# DouAi 0.2.24 正式版：独立模型选择与本地分析提示词

版本 **0.2.24 / 125**，包名 `io.github.yudigaga.douai`，沿用长期签名构建 Release，启用 R8。GitHub 标签为 [`v0.2.24`](https://github.com/yudigaga/DouAi/releases/tag/v0.2.24)，LSPosed 标签为 [`125-0.2.24`](https://github.com/Xposed-Modules-Repo/io.github.yudigaga.douai/releases/tag/125-0.2.24)，两处发布同一份已验证 APK 与 SHA-256 校验文件。本地封存清单保留原 `published=false` 验收快照，远端发布证明另行保存。

## 相对 0.2.22 的累计更新

自动回复和自动评论可各自选择已保存的供应商配置，默认跟随全局；选择不修改全局激活模型，评论区回复沿用自动回复的选择。所选配置的接口、密钥、模型、一级提示词、流式和其他参数分别生效，支持备份及热更新。切换本功能模型会取消尚未提交的旧任务；配置被删除后需重新选择。

修复首次并发生成第三方或 MiniMax 语音时，另一任务先创建缓存目录仍导致误报失败的竞态。真实目录错误继续失败，音频文件、重试及文字回退策略保持原有行为。0.2.23 的独立安装包与 470 项专项属于历史记录，不计为本版执行结果。

## 本次更新

- 本地数据分析可独立选择已保存的供应商配置，默认跟随全局。模型、接口、密钥、一级提示词、流式和其他请求参数来自所选配置，不修改全局、自动回复或自动评论的选择。显式选择无需全局模型处于启用状态；所选配置被删除后需重新选择。
- 新增独立二级提示词和恢复默认；留空使用原分析任务。自定义内容用于调整本地分析的重点和表达，报告字段及统计口径由程序保留。长提示词原样保存并放入任务字段，不套用普通消息的 4000 字符输入限制。
- 模型和提示词在请求准备时固定。设置编辑不会发起网络请求；分析期间禁用编辑，修改后清理旧解读和未交接的报告导出，原始统计保留。关闭页面后拒绝迟到选择或保存。
- 两项新设置纳入普通配置备份，内置帮助与帮助文档同步更新。

## 使用入口

进入“扩展功能 → 本地数据分析 → AI 图表分析”，点击“模型配置”选择已有供应商，再通过“二级提示词”编辑并保存。可用“恢复默认二级提示词”恢复原任务。只有点击“请求 AI 分析”才会发送当前统计。
