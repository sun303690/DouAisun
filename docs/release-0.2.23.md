# DouAi 0.2.23 本地正式版：自动回复与自动评论独立选择模型

版本 **0.2.23 / 124**，包名 `io.github.yudigaga.douai`，使用长期签名构建 Release，启用 R8，未发布远端。

## 本次更新

- 自动回复和自动评论可从已保存的供应商配置中各自选择一个，允许选择不同或相同配置；默认跟随全局模型，选择不修改全局激活配置。
- 所选配置的接口、密钥、模型、一级提示词、流式模式、推理强度及其他请求参数分别生效；评论区回复与私聊、群聊共用自动回复的选择。绑定的配置被删除后需重新选择，不自动切换供应商。
- 新选择支持配置备份和热更新。切换本功能模型会取消尚未提交的旧任务，另一功能的独立选择不会因此改变。
- 修复首次并发生成第三方或 MiniMax 语音时，两条任务同时创建缓存目录导致其中一条误报“无法创建语音缓存”的竞态。真实的目录创建错误仍会失败，音频文件、重试和文字回退策略保持原有行为。

选择入口：先将对应功能的模式设为“AI 模型”，再进入“自动回复 → 回复内容 → 模型配置”或“自动评论 → 评论内容 → 模型配置”。例如已有供应商 A、B、C，可让自动回复使用 A、自动评论使用 B。
